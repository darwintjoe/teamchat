    2

    Locked constraints

    LOCK
    One message = one write. Fan-out is N query re-runs, never N inserts.
    LOCK
    No hot per-group document. Nothing scoped to a group may be written per message — no counters. Rate limits use the transactional limiter keyed by group.
    LOCK
    Metadata / bytes split. The server never proxies media.
    LOCK
    Tree-only for groups. DMs are a named exception — outside every rollup, org-switchable.
    LOCK
    No createdAt on messages. ERP can backdate it. Order by _creationTime.
    3

    Gates — run in this order

    S1Union-variant indexing on first deploy. 4 variant-only fields on groups. Fails → flatten to optional fields. Blocks every schema decision.
    S6Region latency, p50 + p95 from Jakarta. Region cannot be changed after creation.
    S2Insert under load, no per-group counter. Proves the lock.
    S3Widget exchange through ConvexCredentials.
    S510k sessions / 256 queries at burst. The one failure money can't fix in budget.

    State machine — terminal, no shortcuts

    open claimmember claimed doneclaimant done closecloser closed
    archived = withdrawn, not completed. No closed → archived. Hiding a closed task sets actionInbox.archivedAt and leaves status alone. reopened.reason ∈ sender_review | customer_reply. forwarded carries actor / from / to — actorId == fromUserId means self-forward, otherwise it is a reassignment.

    One message, end to end

    1 client calls messages.send — one mutation
    2 one insert into messages · no counter, no group doc write
    3 Convex invalidates every subscriber of that group's feed
    4 each live viewer re-reads one bounded page (≤15 docs)
    5 sender's memberships.lastReadAt advances in the same mutation
    6 webhook fan-out is a scheduled action, never inline

    9

    Traps that will cost you a week each

    Trap 01
    Don't index a variant-only field
    S1 decides this. Build byosCredentials first — it's the cheap probe.
    Trap 02
    Never add a per-group counter
    It looks like the obvious way to do unread and rate caps. It breaks write concurrency under load.
    Trap 03
    Widget identity is never email
    Resolve by hostAppId + externalUserId. Email is mutable and unverifiable from the host.
    Trap 04
    Region is permanent
    Set at deployment creation. Changing it later means export, import, and a new project.
